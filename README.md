# Swiggy_sales_analysis-using-Mysql-Python
Analyzed 197,403 Swiggy sales records using MySQL and Python. Performed data cleaning, validation, duplicate removal, and designed a Star Schema with 1 fact and 5 dimension tables. Built KPIs, conducted business analysis, and created visualizations using Pandas, NumPy, Matplotlib, Seaborn, and Plotly to generate actionable insights.
